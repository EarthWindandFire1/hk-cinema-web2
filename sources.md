# Sources & image credits

## Project data

Adapted from the original local `D:\Python\ymy\web` Demo (`data.js`, `hk_logic.js`, `app.js`, `index.html`). The data file is preserved byte-for-byte. The original Demo has four main charts, six fixed evidence panels, and a film table; all remain available in this version.

The accompanying Group 31 report supplies interpretation and reported statistics (including revenue correlation, 158 plot summaries, and largest-component percentages). Its 2,880-film corpus differs from this local Demo's 2,876 records. The website discloses this difference. Filtered counts always come from the local data.

- [IMDb non-commercial datasets](https://developer.imdb.com/non-commercial-datasets/)
- [Wikidata country of origin property](https://www.wikidata.org/wiki/Property:P495)
- [Hong Kong Film Awards](https://www.hkfaa.com/)
- [Box Office Mojo Hong Kong charts](https://www.boxofficemojo.com/year/?area=HK)
